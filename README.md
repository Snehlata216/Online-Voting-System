# 🗳️ Online Voting System

A secure, role-based web application for conducting online elections and polls.  
Built with **React (frontend)**, **Node.js + Express (backend)**, and **MySQL (database)**.

---

## 🚀 Features
- **User Authentication**: Secure login and role-based access (Admin, Voter).
- **Candidate Management**: Admins can add, update, and manage candidates.
- **Polls & Elections**: Create, view, and manage active polls/elections.
- **Voting Panel**: Voters can cast ballots and view real-time results.
- **Feedback Module**: Collect feedback tied to candidate IDs for transparency.
- **Notifications**: Real-time updates for users on election status and results.
- **Reports & Analytics**: Export results to CSV and visualize with charts.
- **Defensive UI**: Error boundaries and normalized API responses to prevent crashes.
